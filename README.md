# 📓 워드 이스케이프 100 : 마법 어휘 연구소 탈출 (Word Escape 100)

> **초등학교 6학년 필수 영단어 100개 마스터 방탈출 웹앱**  
> Doodle / Notebook / Blue Ink 비주얼 스타일 & 영국식 발음(British English, en-GB) TTS 지원

---

## 🌟 주요 특징

1. **테마별 5개 룸(Room) 기반 탈출 스테이지 (총 100단어)**
   - **Room 1: 학교와 교실 (20단어)** - `pencil`, `notebook`, `eraser`, `library`, `blackboard`, `homework` 등
   - **Room 2: 일과와 감정 (20단어)** - `morning`, `breakfast`, `shower`, `happy`, `excited`, `nervous` 등
   - **Room 3: 마을과 음식 (20단어)** - `market`, `hospital`, `station`, `delicious`, `vegetable`, `sandwich` 등
   - **Room 4: 자연과 계절 (20단어)** - `spring`, `summer`, `weather`, `forest`, `protect`, `nature`, `earth` 등
   - **Room 5: 직업과 미래 (20단어)** - `doctor`, `police`, `pilot`, `scientist`, `future`, `dream`, `space` 등

2. **4가지 다채로운 암호 해독 미션**
   - **미션 1: 어휘 의미 암호** (4지선다 의미 매칭)
   - **미션 2: 음성 단서 추리** (영국식 발음을 듣고 올바른 단어 찾기)
   - **미션 3: 스펠링 철자 퍼즐** (빈칸 철자를 채워 단어 완성)
   - **미션 4: 비상 금고 마스터 락** (문맥 예문 빈칸 추리)

3. **Doodle / Notebook / Blue Ink 감성 디자인**
   - 파란 볼펜 잉크(`#0000CD`), 빨간 첨삭 잉크(`#FF0000`), 줄노트 용지 질감
   - 손글씨 폰트(Gaegu, Nanum Pen Script, Patrick Hand)
   - 포스트잇 힌트 메모, 마스킹 테이프, 커피 얼룩 워터마크

4. **영국식 원어민 발음 (en-GB TTS)**
   - Web Speech API를 활용하여 영국 영어 원어민 발음 자동 재생

5. **부가 학습 모드**
   - **100단어 메모 도감**: 검색 및 룸별 필터링, 원어민 발음 무제한 청취
   - **스피드 골든벨 모드**: 12초 타임어택 콤보 챌린지

- **GitHub Pages**: 웹 주소를 통해 모바일, 태블릿, PC, 전자칠판 어디서나 바로 접속할 수 있습니다.
